# Sistema de Controlo de Níveis de Água 💧

Simulador em Python desenvolvido para o monitoramento automatizado de um reservatório de água[cite: 5, 6]. O projeto utiliza estruturas de dados em lista e a biblioteca `colorama` para exibir alertas visuais dinâmicos diretamente no terminal, associando cada nível a uma situação crítica e a uma cor específica[cite: 5, 6].

---

## 🚀 Funcionalidades

* **Estrutura de Dados em Lista:** Organização e mapeamento dos cinco níveis operacionais do reservatório[cite: 5, 6].
* **Alertas Visuais Coloridos:** Utilização da biblioteca `colorama` para colorir automaticamente as mensagens no terminal (do vermelho crítico ao azul de alerta máximo)[cite: 5, 6].
* **Função Modularizada:** Código estruturado com a função `verificar_reservatorio()` para gerir a exibição formatada com restauro automático de estilo (`autoreset`)[cite: 5, 6].

---

## 🛠️ Tecnologias Utilizadas

* **Python 3.x**[cite: 7]
* **Biblioteca Colorama** (para formatação de texto colorida no terminal)[cite: 5, 6]
